3. CALL CHAIN
============================================================

```
ATAS (OnCalculate callback, per bar)
  -> IQIAIndicator.OnCalculate(bar, value)                                    [IQIAIndicator.cs:246]
       -> MarketContextBuilder.Build(bar, CurrentBar)                        [Core/MarketContextBuilder.cs:52]
            -> Core.MarketContext { Price, Volume, ... } (single-bar OHLCV snapshot, NO history list)
       -> IQIAIndicator.CreateScientificMarketContext(context, bar)          [IQIAIndicator.cs:720]
            -> builds `history`: List<decimal> of up to 500 Close prices,
               GetCandle(index).Close for index in [max(0,bar-499)..bar], ascending
            -> Engine.ScientificModels.Abstractions.MarketContext(Timestamp, CurrentBar, history, ...)
       -> SignalEngine.Process(scientificMarketContext, methodologySelection, trace) [Signal/SignalEngine.cs:48]
            -> ScientificModelRegistry.Resolve(methodologySelection) -> active models incl. KalmanFilterModel
            -> foreach model: ScientificModelContext { MarketContext, DecisionResult, MethodologySelection, ScientificResults }
            -> KalmanFilterModel.Evaluate(context)                           [MeanReversion/KalmanFilterModel.cs:53]
                 -> history = context.MarketContext.History (the exact 500-cap list built above, untouched)
                 -> windowStart = max(0, history.Count - 20); windowedHistory = history[windowStart..]
                 -> observations = windowedHistory as double[]
                 -> EstimateMeasurementNoise(observations) -> MeasurementNoise
                 -> Kalman recursion over `observations` -> FilterCovariance, KalmanGain
                 -> InnovationVariance = FilterCovariance + MeasurementNoise
                 -> InnovationStd = sqrt(InnovationVariance)
  -> ScientificDatasetRecord.From(...) [if EnableScientificDataset]           [Core/Calibration/ScientificDatasetRecord.cs:41]
       -> iterates result.Metrics generically -> "KalmanFilterModel.<key>" columns in the export
```

Two distinct `MarketContext` types exist in the codebase and this was the first ambiguity resolved:
`IQIAIndicator.Core.MarketContext` (`Core/MarketContext.cs`) is the raw, single-bar ATAS snapshot with
**no** history field at all — `MarketContextBuilder` only ever produces this one.
`IQIAIndicator.Engine.ScientificModels.Abstractions.MarketContext` (a `record` with the `History`
property `KalmanFilterModel` actually reads) is built separately, once per bar, by
`IQIAIndicator.CreateScientificMarketContext` — this is the single point where "HistoryLength" is
defined and populated.

5. WINDOW CONFIGURATION
============================================================

`private const int ObservationWindowSize = 20;` — `KalmanFilterModel.cs:51`. A `private const` on the
one class that reads it; not merely "a constant exists somewhere" — traced directly into the windowing
line two lines into `Evaluate()`:

```csharp
int windowStart = Math.Max(0, history.Count - ObservationWindowSize);      // KalmanFilterModel.cs:82
IReadOnlyList<decimal> windowedHistory = windowStart == 0 ? history : history.Skip(windowStart).ToList();
```

`observations = windowedHistory.Select(x => (double)x).ToArray()` feeds directly into
`EstimateMeasurementNoise(observations)`, `EstimateInitialVariance(observations)`, and the Kalman
recursion loop (`for (int i = 1; i < observations.Length; i++)`). **PROVEN**: no indirection, no
override, no dead code path.
