# IQIA Research

Ce dossier contient les recherches scientifiques réalisées
avant toute intégration dans IQIA.

Une recherche ne signifie pas qu'un modèle sera intégré.

Chaque document suit le même protocole scientifique :

1. Historique

2. Théorie mathématique

3. Hypothèses

4. Applications financières

5. Forces

6. Faiblesses

7. Compatibilité IQIA

8. Proposition d'architecture

9. Verdict

Les modèles retenus seront ensuite documentés
dans les QDE avant leur implémentation.
